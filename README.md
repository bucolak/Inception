# Inception

A small web infrastructure built with **Docker Compose**: NGINX, WordPress (PHP-FPM) and MariaDB, each in its own container built from my own Dockerfiles on `debian:bookworm` — no ready-made images from Docker Hub.

> **Status:** in progress.

## Architecture

```
        HTTPS :443 (TLS 1.2 / 1.3 only)
                 │
          ┌──────▼──────┐   FastCGI :9000   ┌──────────────────────┐   :3306   ┌─────────────┐
 Browser ─┤    NGINX    ├──────────────────▶│ WordPress + PHP-FPM  ├──────────▶│   MariaDB   │
          └──────┬──────┘                   └──────────┬───────────┘           └──────┬──────┘
                 │        docker network: inception (bridge)                        │
                 └──── wordpress_data volume ──────────┘               mariadb-data volume
                         /home/bucolak/data/wordpress                  /home/bucolak/data/mariadb
```

- **NGINX** is the only entry point; it listens on port 443 with a self-signed certificate generated by OpenSSL at build time and forwards PHP requests to WordPress over FastCGI.
- **WordPress** runs on PHP-FPM 8.2 without a web server. On first start, its entrypoint script uses **WP-CLI** to create `wp-config.php`, install the site and create an admin and a regular user.
- **MariaDB** creates the database and user on first start from environment variables.
- Both volumes are bind-mounted to `/home/bucolak/data` on the host, so data survives container rebuilds.
- Containers restart automatically (`restart: unless-stopped`) and talk to each other only through the private `inception` network.

## Usage

Create `srcs/.env` (never committed):

```env
DOMAIN_NAME=bucolak.42.fr
MYSQL_DATABASE=wordpress
MYSQL_USER=...
MYSQL_PASSWORD=...
MYSQL_ROOT_PASSWORD=...
WORDPRESS_DB_HOST=mariadb:3306
WP_TITLE=Inception
WP_ADMIN_USER=...
WP_ADMIN_PASSWORD=...
WP_ADMIN_EMAIL=...
WP_USER=...
WP_USER_PASSWORD=...
WP_USER_EMAIL=...
```

Add `127.0.0.1 bucolak.42.fr` to `/etc/hosts`, then:

```bash
make        # create data folders, build images and start containers
make down   # stop containers
make clean  # remove containers, volumes and images
make fclean # clean + delete data on the host
make re     # rebuild from scratch
```

Open `https://bucolak.42.fr` (accept the self-signed certificate).
